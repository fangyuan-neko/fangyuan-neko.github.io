Hexo的安装

npm install hexo-cli -g一键安装

注：

安装速度过慢的话，可以考虑更换软件源(不过笔者也是半吊子，不知道有没有危险和缺点)

可以尝试更换淘宝的源npm config set registry https://registry.npm.taobao.org

这样npm就会从国内某位好心人提供的高速宽带下载需要的包

如果需要恢复成原来的官方地址只需要执行如下命令:

npm config set registry https://registry.npmjs.org

检查

npm config get registry

Hexo博客系统配置

下载

hexo init
sudo npm install

小尝试

在当前文件夹输入命令hexo g+ hexo s//分别是“generate”（生成）和“server”（服务器）的意思

然后根据提示在浏览器中访问localhost:4000就可以看到成果啦！

更换主题

这里笔者用的是ayer主题 详见官方教程

部署

安装git插件

npm install hexo-deployer-git --save

然后在博客根目录的_config.yml加上

deploy:
  type: git
  repo: git@github.com:<yourname>/<yourname>.github.io.git
  branch: main
  massage: reflash

注意GitHub21年3月后禁用了账号密码连接的方式，因此只能用Git连接。 如有其它问题，请参见官方发布指南
