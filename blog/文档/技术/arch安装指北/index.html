必要配置

其实想最快装好系统不必按教程一步一步安装，只要划好硬盘分区，装上最基本的包就可以了。

网络配置

无线网络

因为ArchLinux安装包中只有iwd,所以本教程先用iwd联网，再下载更好用的NetworkManager

iwd食用方法

iwctl #打开交互式命令界面
    device list #打印设备名，也就是<dev>
    station <dev> get-networks #扫描无线网络
    station <dev> connect <SSID> #联网

其中，<dev>通常是wlan0

试试网络吧！

ping gitee.com

NetworkManager食用方法

sudo systemctl start NetworkManager
nmcli dev wifi connect <SSID> password <password> #联网
nmcli dev wifi show #打印网络配置

有线网络

正常情况下直接用就成，出了问题

打开ssh

systemctl start sshd #打开ssh服务进程
ip addr #查看ip地址

然后换一台电脑，连上ssh,就可以愉快地复制粘贴啦！

源配置

有两种方法

  • 用reflector脚本
reflector --country China --age 12 --protocol https --sort rate --save /etc/pacman.d/mirrorlist

来排序源的速度

如果提示失败，不用担心检查一下文件是否已写入即可

cat /etc/pacman.d/mirrorlist
  • 使用编辑器修改，在/etc/pacman.d/mirrorlist中添加两条配置
Server = https://mirrors.ustc.edu.cn/archlinux/$repo/os/$arch
Server = https://mirrors.tuna.tsinghua.edu.cn/archlinux/$repo/os/$arch

*安装失败：*运行pacman -Sy archlinux-keyring，如果不行就pacman-key --refresh-keys

磁盘

分盘

磁盘划分是系统安装的重中之重，如果你是小白，建议按我的方式来划分。

安装一个基本的、稳定的操作系统，至少需要3块磁盘，一块使用fat32用于引导系统，大约1G左右，一块使用ext或brtfs的系统盘，正常情况下60-120G,一块使用ext或brtfs的数据盘，大小随意。

使用cfdisk /dev/sdxx划分磁盘，由于是图形界面，不再过多解释。

文件系统

设置引导分区

mkfs.fat -F 32 /dev/<你的引导分区，如sda1>

系统、数据盘日常使用用ext4即可。

mkfs.ext4 /dev/<你的系统、数据分区，如sda2/3>
使用btrfs
mkfs.btrfs -f -m single -L <卷名称> /dev/sdax

并在挂载后执行

btrfs subvolume create /mnt/@ #创建根子卷
umount /mnt
mount /dev/sdax /mnt -o subvol=@ #重新挂载btrfs子卷

挂载文件系统

原理

以安装环境中的/mnt当作新系统的/，/需要什么就在/mnt挂载什么就可以了。 例如，挂载/mnt/boot作为新系统/boot（必有）；挂载/mnt/home/fangyaun作为新系统的主目录/home/fangyuan。 总之，你只需要在要挂载的硬盘路径后加/mnt就可以了。

mount -t btrfs -o compress=lzo /dev/sdax /mnt

安装

pacstrap -K /mnt base base-devel linux linux-firmware neovim networkmanager openssh git #这已经是精简到不能再精简的了

若此脚本错误，则下载

pacman -Sy archlinux-keyring

换源相关

pacman -Sy archlinuxcn-keyring

启动引导

这是最关键的一步，没做好启动引导是进不了系统的。

arch-chroot /mnt # 以su的身份进入新系统
pacman -S grub efibootmgr # ps:嫌丑的话也可用refind
grub-install --target=x86_64-efi --efi-directory=<你的引导分区，按上面的教程是/boot> --bootloader-id=<随意>
grub-mkconfig -o /boot/grub/grub.cfg

非必要命令

这些命令都是在装好系统后再配置也是没有问题的

timedatectl set-ntp true # 设置时钟ntp服务器同步网络时间
hostnamectl <your name> # 你的电脑名称
